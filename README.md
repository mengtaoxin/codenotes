# codenotes

Algorithm notes with TypeScript implementations and Vitest tests.

## Setup

```bash
npm install
```

## Scripts

| Command | Description |
| --- | --- |
| `npm test` | Run tests once |
| `npm run test:watch` | Watch mode |
| `npm run typecheck` | TypeScript check |

## Layout

```
algorithms/         # algorithm implementations
algorithms-tests/   # Vitest suites (tests only)
toolings/           # shared test helpers / tooling
```
