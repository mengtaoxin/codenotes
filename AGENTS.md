## Core Rules

- `algorithms/` is for personal practice. Do **not** edit, refactor, or “fix” existing files there (including comments and signatures).
- You **may** create **new** files under `algorithms/` as **skeletons only**: exports, types, and empty/`TODO` bodies — no complete algorithm implementations unless the user explicitly asks.
- You **may** freely work in `algorithms-tests/` and `toolings/` (tests, helpers, fixtures).
- When writing or changing tests, follow [docs/tests-requirements.md](docs/tests-requirements.md).
